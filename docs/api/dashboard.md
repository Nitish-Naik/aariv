# Dashboard API

Endpoints for the daily briefing, calendar, upcoming meeting, activity feed, manual scan, and per-app snapshots.

All paths are relative to the [base URL](./README.md).

---

## GET /api/dashboard/briefing

Return an AI-generated daily briefing for the authenticated user. The briefing is cached in-process for 15 minutes per user to avoid redundant AI calls.

### Auth Required

Yes

### Consumes Quota

Yes — one quota unit is charged each time a new AI briefing is generated. Cached responses and "caught up" responses (zero new events since last check) do **not** consume quota.

### Tier Requirement

Paid plan (Starter or Pro). Free users are allowed during the first 3 days after account creation (grace period); subsequent requests return HTTP `403`.

### Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `timezone` | `string` | `"UTC"` | IANA timezone for activity logging (e.g., `"America/New_York"`). Does not affect event time boundaries. |
| `force` | `boolean` | `false` | If `true`, bypass the 15-minute cache and generate a fresh briefing immediately. |

### Response

```json
{
  "subtitle": "A full day ahead. I've organized what needs you.",
  "is_calm": false,
  "counts": {
    "meetings": 3,
    "emails": 12,
    "focus_hours": 2.5,
    "needs_judgment": 2
  },
  "proposals": [
    {
      "app": "gmail",
      "title": "Client followed up on invoice",
      "description": "Client ABC replied to your invoice email. CalmPilot drafted a confirmation reply.",
      "priority": "high",
      "actions": ["Draft with CalmPilot", "Review draft"]
    }
  ],
  "events": [
    {
      "id": "event_xyz",
      "title": "Team Standup",
      "startTime": "2025-03-30T09:00:00Z",
      "endTime": "2025-03-30T09:30:00Z",
      "color": null
    }
  ],
  "insight": "CalmPilot cleared 3 low-priority emails and organized your Slack mentions.",
  "briefing_type": "morning",
  "is_incremental": false,
  "since": null
}
```

| Field | Type | Description |
|---|---|---|
| `subtitle` | `string` | One-sentence summary of the day generated by GPT-4o-mini. |
| `is_calm` | `boolean` | `true` if there are no urgent items and low overall activity. |
| `counts.meetings` | `integer` | Number of calendar events today. |
| `counts.emails` | `integer` | Number of new email trigger events since the last briefing. |
| `counts.focus_hours` | `number` | Estimated free hours between 9 AM and 6 PM (UTC) after accounting for meetings. |
| `counts.needs_judgment` | `integer` | Number of proposals classified as high-priority by the AI. |
| `proposals` | `array` | 0–3 actionable items the AI suggests. |
| `proposals[].app` | `string` | Lowercase app slug (`"gmail"`, `"slack"`, etc.). |
| `proposals[].title` | `string` | Short headline. |
| `proposals[].description` | `string` | 1–2 sentence explanation. |
| `proposals[].priority` | `string` | `"high"`, `"medium"`, or `"low"`. |
| `proposals[].actions` | `string[]` | 1–2 button label strings. |
| `events` | `array` | Calendar events for today. |
| `events[].id` | `string` | Google Calendar event ID. |
| `events[].title` | `string` | Event summary. Defaults to `"(No Title)"`. |
| `events[].startTime` | `string \| null` | ISO 8601 datetime or date string. |
| `events[].endTime` | `string \| null` | ISO 8601 datetime or date string. |
| `events[].color` | `string \| null` | Hex color if the event has a Google Calendar `colorId`, otherwise `null`. |
| `insight` | `string` | Single sentence from the AI about something it noticed. Empty string if nothing to note. |
| `briefing_type` | `string` | `"first"` (new user), `"morning"` (>10 h since last briefing), `"incremental"` (<10 h), `"caught_up"` (no new events), or `"error"`. |
| `is_incremental` | `boolean` | `true` if this briefing covers only events since the last cursor (not a full day). |
| `since` | `string \| null` | ISO timestamp of the cursor used for this briefing. `null` for first-time users. |

**"Caught up" response** (no new events since last check — no AI call, no quota charge):

```json
{
  "subtitle": "You're all caught up. Nothing new since you last checked.",
  "is_calm": true,
  "counts": {"meetings": 0, "emails": 0, "focus_hours": 0, "needs_judgment": 0},
  "proposals": [],
  "events": [],
  "insight": "",
  "briefing_type": "caught_up",
  "is_incremental": true,
  "since": "2025-03-30T06:00:00Z"
}
```

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |
| `402` / `403` | Feature requires a paid plan (free user, post-grace) — `detail: "briefing_requires_paid_plan"` |
| `429` | Monthly quota exhausted |

## GET /api/dashboard/calendar

Fetch Google Calendar events for today, tomorrow, or the next 7 days.

### Auth Required

Yes

### Consumes Quota

No

### Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `range` | `string` | `"today"` | Time window. Accepted values: `"today"`, `"tomorrow"`, `"week"`. |
| `timeMin` | `string` | — | ISO 8601 datetime override. If both `timeMin` and `timeMax` are provided they take precedence over `range`. |
| `timeMax` | `string` | — | ISO 8601 datetime override. Must be provided together with `timeMin`. |

The user's timezone is read from `profiles.timezone` to compute correct day boundaries. Defaults to UTC if not set.

### Response

```json
{
  "events": [
    {
      "id": "event_xyz",
      "title": "Team Standup",
      "startTime": "2025-03-30T09:00:00Z",
      "endTime": "2025-03-30T09:30:00Z",
      "color": "#4285F4",
      "allDay": false
    }
  ],
  "grouped": {
    "2025-03-30": [
      {
        "id": "event_xyz",
        "title": "Team Standup",
        "startTime": "2025-03-30T09:00:00Z",
        "endTime": "2025-03-30T09:30:00Z",
        "color": "#4285F4",
        "allDay": false
      }
    ]
  }
}
```

| Field | Type | Description |
|---|---|---|
| `events` | `array` | Flat list of all events in the requested range. Empty array on error or no calendar connected. |
| `events[].id` | `string` | Google Calendar event ID. |
| `events[].title` | `string` | Event summary. Defaults to `"(No Title)"`. |
| `events[].startTime` | `string \| null` | ISO 8601 datetime (or date-only string for all-day events). |
| `events[].endTime` | `string \| null` | ISO 8601 datetime (or date-only string for all-day events). |
| `events[].color` | `string \| null` | `"#4285F4"` if the event has a Google Calendar `colorId`, otherwise `null`. |
| `events[].allDay` | `boolean` | `true` when the event is an all-day event (no `dateTime`, only `date`). |
| `grouped` | `object` | Events keyed by `YYYY-MM-DD` date string. Useful for week view rendering. |

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |

On any upstream error (Composio, calendar API) the endpoint returns `{"events": [], "grouped": {}}` with HTTP `200` rather than propagating the error.

## GET /api/dashboard/upcoming-meeting

Get the next calendar meeting starting within the next 15 minutes.

### Auth Required

Yes

### Consumes Quota

No

### Request

No body or query parameters.

### Response

```json
{
  "meeting": {
    "id": "event_xyz",
    "title": "Team Standup",
    "startTime": "2025-03-30T09:00:00Z",
    "endTime": "2025-03-30T09:30:00Z",
    "meetLink": "https://meet.google.com/abc-defg-hij",
    "attendees": ["alice@example.com", "bob@example.com"]
  }
}
```

Returns `{"meeting": null}` when no meeting is starting in the next 15 minutes.

| Field | Type | Description |
|---|---|---|
| `meeting` | `object \| null` | The next upcoming meeting, or `null`. |
| `meeting.id` | `string` | Google Calendar event ID. |
| `meeting.title` | `string` | Event summary. |
| `meeting.startTime` | `string` | ISO 8601 datetime. |
| `meeting.endTime` | `string` | ISO 8601 datetime. |
| `meeting.meetLink` | `string \| null` | Google Meet URL if present in the event. |
| `meeting.attendees` | `string[]` | List of attendee email addresses. |

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |
| `500` | Unexpected error fetching meeting data |

## GET /api/dashboard/recent-events

Fetch recent trigger events (webhook events from connected apps) for the authenticated user.

### Auth Required

Yes

### Consumes Quota

No

### Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `limit` | `integer` | `20` | Number of events to return. Min `1`, max `100`. |

### Response

```json
{
  "events": [
    {
      "id": "evt_abc",
      "triggerSlug": "GMAIL_NEW_EMAIL_TRIGGER",
      "app": "gmail",
      "status": "completed",
      "preview": "Re: Invoice #1042 — looks good, thanks!",
      "processingTimeMs": 142,
      "error": null,
      "createdAt": "2025-03-30T08:45:00Z"
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `events` | `array` | List of formatted trigger events, ordered newest-first. |
| `events[].id` | `string` | Unique event ID. |
| `events[].triggerSlug` | `string` | Composio trigger identifier (e.g., `"GMAIL_NEW_EMAIL_TRIGGER"`). |
| `events[].app` | `string` | Lowercase app prefix derived from the slug (e.g., `"gmail"`). |
| `events[].status` | `string` | `"received"`, `"processing"`, `"completed"`, or `"failed"`. |
| `events[].preview` | `string` | Up to 200 characters of the event payload (subject, title, text, summary, or message). |
| `events[].processingTimeMs` | `integer \| null` | How long the event took to process in milliseconds. |
| `events[].error` | `string \| null` | Error message if status is `"failed"`. |
| `events[].createdAt` | `string` | ISO 8601 timestamp. |

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |

Returns `{"events": []}` on any upstream error.

## GET /api/dashboard/feed

Paginated activity feed with filtering and search. Extends `/recent-events` with offset-based pagination, app/status filters, and summary stats.

### Auth Required

Yes

### Consumes Quota

No

### Query Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `limit` | `integer` | `25` | Events per page. Min `1`, max `500`. |
| `offset` | `integer` | `0` | Number of events to skip (for pagination). |
| `app` | `string` | — | Filter by app prefix (e.g., `"gmail"`). Case-insensitive. |
| `status` | `string` | — | Filter by status. Accepted values: `"received"`, `"processing"`, `"completed"`, `"failed"`. |
| `search` | `string` | — | Full-text search against `trigger_slug` and email subject in the payload. |

### Response

```json
{
  "events": [
    {
      "id": "evt_abc",
      "triggerSlug": "GMAIL_NEW_EMAIL_TRIGGER",
      "app": "gmail",
      "status": "completed",
      "preview": "Re: Invoice #1042",
      "processingTimeMs": 142,
      "error": null,
      "createdAt": "2025-03-30T08:45:00Z"
    }
  ],
  "total": 84,
  "hasMore": true,
  "stats": {
    "total": 84,
    "completed": 79,
    "failed": 5,
    "apps": 3
  }
}
```

| Field | Type | Description |
|---|---|---|
| `events` | `array` | Page of formatted trigger events (same shape as `/recent-events`). |
| `total` | `integer` | Total count of all matching events (before pagination). |
| `hasMore` | `boolean` | `true` if there are more events beyond this page. |
| `stats` | `object \| null` | Summary stats — only included on the first page (`offset=0`). `null` on subsequent pages. |
| `stats.total` | `integer` | Total trigger events ever received by this user. |
| `stats.completed` | `integer` | Total events with status `"completed"`. |
| `stats.failed` | `integer` | Total events with status `"failed"`. |
| `stats.apps` | `integer` | Number of distinct apps in the current result page. |

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |

Returns `{"events": [], "total": 0, "hasMore": false, "stats": {...zeros}}` on any upstream error.

## POST /api/dashboard/scan

Trigger a bootstrap scan for newly connected apps. Fetches recent data (last emails, calendar events, DMs) and writes trigger events so the dashboard shows real content immediately after the user connects an app.

### Auth Required

Yes

### Consumes Quota

No

### Rate Limit

3 scan calls per user per hour (in-memory). Returns HTTP `200` with `{"status": "rate_limited", "events": 0}` when exceeded.

### Request

No body required.

### Response

```json
{
  "status": "completed",
  "events": 15,
  "apps": ["gmail", "googlecalendar", "slack"]
}
```

| Field | Type | Description |
|---|---|---|
| `status` | `string` | `"completed"`, `"rate_limited"`, `"no_apps"`, `"skipped"`, or `"error"`. |
| `events` | `integer` | Number of trigger events written to the database during this scan. |
| `apps` | `string[]` | Lowercase slugs of apps that were scanned. Omitted when `status` is not `"completed"`. |

**Status values:**

| Value | Meaning |
|---|---|
| `completed` | Scan ran successfully. |
| `rate_limited` | User has called this endpoint 3+ times in the last hour. |
| `no_apps` | User has no active connected apps to scan. |
| `skipped` | Database or Composio client was not ready. |
| `error` | Unexpected error during the scan. |

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |

## GET /api/dashboard/app-snapshot/{app_slug}

Return a quick live snapshot of a just-connected app. Used by the post-connect modal to display real numbers immediately after the user authorizes an app.

### Auth Required

Yes

### Consumes Quota

No

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| `app_slug` | `string` | App identifier. Supported values: `"gmail"`, `"googlecalendar"` (also `"google-calendar"`), `"slack"`. |

### Response

The `stats` object shape depends on the app.

**Gmail:**

```json
{
  "app": "gmail",
  "stats": {
    "total_emails": 20,
    "urgent_count": 2,
    "top_senders": [
      {"name": "Alice Smith", "count": 5},
      {"name": "Bob Jones", "count": 3}
    ]
  }
}
```

| Field | Description |
|---|---|
| `stats.total_emails` | Number of inbox emails fetched (up to 20). |
| `stats.urgent_count` | Emails with urgency keywords in the subject (`urgent`, `asap`, `important`, `action required`, `deadline`). |
| `stats.top_senders` | Up to 3 most frequent senders as `{name, count}` objects. |

**Google Calendar:**

```json
{
  "app": "googlecalendar",
  "stats": {
    "total_meetings": 5,
    "next_event": {
      "title": "Team Standup",
      "time": "2025-03-30T09:00:00Z"
    },
    "conflicts": 1
  }
}
```

| Field | Description |
|---|---|
| `stats.total_meetings` | Number of events remaining today (from now to midnight UTC). |
| `stats.next_event` | Title and start time of the soonest event, or `null` if none. |
| `stats.conflicts` | Number of overlapping event pairs detected. |

**Slack:**

```json
{
  "app": "slack",
  "stats": {
    "dm_conversations": 10,
    "unread_dms": 3
  }
}
```

| Field | Description |
|---|---|
| `stats.dm_conversations` | Number of direct message conversations (up to 10). |
| `stats.unread_dms` | DM conversations with unread messages. |

**Unknown or unsupported app:**

```json
{
  "app": "notion",
  "stats": {}
}
```

### Errors

| Status | Cause |
|---|---|
| `401` | Missing or invalid JWT |

On any upstream error the endpoint returns `{"app": "<slug>", "stats": {}}` with HTTP `200`.
