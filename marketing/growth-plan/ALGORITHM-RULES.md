# X Algorithm Rules — FOLLOW THESE ON EVERY TWEET

## Non-Negotiable Rules

1. **NEVER put a link in the main tweet** — reply to your own tweet with the link 2 min later
2. **ALWAYS end with a question** — replies are 13.5x weight
3. **Post at 9am EST or 1pm EST** — when US founders are online
4. **Reply to your own tweet** within 5 min with: link + extra context + tag a relevant person
5. **Use line breaks and → arrows** — increases dwell time (3x weight)

## Tweet Structure Template

```
[Hook — 1 line that makes someone stop scrolling]
[blank line]
[Body — 3-5 lines with → or numbers]
[blank line]
[Question — forces reply]
```

## After Posting Checklist

- [ ] Reply to your own tweet with calmpilot.app link (2 min after)
- [ ] Reply to your own tweet with extra context (5 min after)
- [ ] Like/reply to the first 3 people who engage (within 30 min)
- [ ] Share in relevant DM groups if you have any

## What KILLS Reach

- Links in main tweet (0.5x penalty)
- No engagement in first 30 min
- Posting more than 5x/hour
- "Like if you agree" type engagement bait
- Identical copy-paste replies
