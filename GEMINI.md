## Aariv UI — One-Page Brief

### How the UI should look

Aariv should look **quiet, composed, and intentional**.

* Minimal screens, never crowded
* Soft colors, neutral tones
* Rounded cards with generous spacing
* No dashboards, no charts, no clutter
* Stacked cards instead of lists
* A calm calendar timeline, not a control panel
* A subtle copilot input at the bottom — always available, never demanding

Nothing flashes.
Nothing blinks.
Nothing rushes the user.

The UI feels **prepared**, not busy.

---

### How the user should feel

When a user opens Aariv, they should feel:

* 😌 **Relieved** — “I’m not behind.”
* 🧠 **Clear** — “This makes sense.”
* 🤝 **In control** — “Nothing happens without me.”
* 🌿 **Calm** — “I don’t need to react right now.”
* ✨ **Supported** — “Someone thoughtful is looking ahead for me.”

Aariv should never make the user feel:

* anxious
* pressured
* monitored
* rushed
* judged

---

### Emotional promise

> **“You don’t need to manage everything.
> I’ve prepared it. You decide.”**

---

### What Aariv is *not*

* Not a task manager
* Not a notification app
* Not a dashboard
* Not an automation engine
* Not a productivity race

---

### The ultimate test

If a user opens the app late at night and thinks:

> *“Good. Nothing urgent. I can rest.”*

Then the UI is correct.

If the UI makes the user want to **do more**, **check more**, or **fix something immediately** — it’s wrong.

---

### In one sentence

> **Aariv’s UI should feel like a calm, intelligent presence that quietly prepares your day without ever demanding your attention.**

This is the north star.
